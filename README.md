Stellar Burgers Project
Проект автоматизации тестирования веб-приложения Stellar Burgers, включающий UI-тесты и unit-тесты для логики бургера.

🛠 Технологии
Языки и фреймворки:
Java 11 - основной язык программирования

JUnit 4 - фреймворк для тестирования

Mockito - библиотека для мокирования

Selenium WebDriver 4.15.0 - автоматизация браузера

RestAssured 5.3.0 - API тестирование

Maven - управление зависимостями
